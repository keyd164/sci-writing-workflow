# Figure Legend

让读者能够正确解读图形，同时将完整方法和讨论留在各自章节。图注解释图中实际呈现的内容，不能补造图未展示或来源未证实的事实。

## 范围与输入

- 先沿用 `paper-workflow` 的当前状态和作者决定；授权范围不因调用本技能扩大，也不新增审批步骤。
- 对已有图，查看当前实际图件，并核对相关源数据、统计输出、图注和对应 Methods/Results。任务只给出文本时，可以编辑文本，但把未看图的覆盖限制放在交付说明中。
- 仅处理图注时不要求选择 Python/R，不重画图、不重估模型。若需要修改图或补做检验，转交现有绘图/分析流程，沿用已选后端和授权范围。
- 期刊格式来自目标刊已核实的官方规则；没有明确规则时沿用稿件格式。Nature 的标题、标点、字数或 Source Data 套语不能自动成为其他期刊要求。

## 撰写和核验

按实际图件选择下列必要信息，不强行把每项塞入每一幅图：

| 信息 | 核验问题 |
|---|---|
| 总题 | 能否用短标题准确说明整图对象或比较，而非夸大结论？ |
| 分面 | a/b/c 与实际位置、结局、时期、情景和分析一一对应吗？ |
| 坐标与编码 | 颜色、形状、线、阴影、点、箱体、须和环形面积分别代表什么？是否有缩放、对数或截断？ |
| 样本和单位 | n 指国家、国家年、个体还是独立重复？是否等权/加权，哪些面板使用汇总值？ |
| 估计与不确定性 | 是均值、中位数、回归系数还是派生差值？带/误差线是SD、SE、系数CI、bootstrap区间、模型范围还是预测区间？ |
| 检验标识 | 检验对象、单双侧、比较集合、校正方法和图中P值/星号对应关系是否明确？ |
| 参照和方向 | 差值是谁减谁，分母是什么，参照暴露/时期是什么，是否混淆水平、变化和变化之差？ |
| 缩写与引用 | 本图所需缩写、单位及补充定位是否齐全？图号、表号和页码与本次交付一致吗？ |

### 统计和数值边界

- 只报告已执行并有输出的检验、样本量和校正。分组图可以仅描述分布；有统计比较主张或作者要求显著性标识时，须有匹配的检验证据，不能凭视觉补星号。
- 对箱线图区分国家多年均值和国家年记录，不能把重复测量写成独立样本。按实际实现解释中位数、IQR、须与异常点；不能默认所有箱线图都用1.5 IQR。
- 不把分布检验写成调整后的暴露效应、斜率差异或易感性证据；不显著不等于等效。
- 多重比较说明校正覆盖的实际比较集合，不能把原始P值标成校正后P值。
- 区间类型按来源分别命名；系数CI和气候模型范围不能合称“总不确定性”或“预测区间”。非对称区间保持非对称。
- 不能为使数字直观而删负号、取绝对值或改比较对象。作者已授权反转方向时，估计D变为−D，区间[L,U]变为[−U,−L]；同时更新图、表、正文、标签和显示数据，原输出保留。
- 新分析、缺失统计定义或图文数值冲突交由 evidence-lock 核实，不能通过改图注掩盖。

### 语言取舍

**Methods 去重限制（作者要求）**：Methods或补充方法已说明的内容，图注原则上不再重复。逐句检查：删去本句会使读者误认面板、符号、单位、独立样本、区间、检验标识或参照方向吗？不会则删除；会则仅保留最短的读图定义，不复述完整分析过程。“自足”指能够解码图形，不意味着把Methods缩写后再写一遍。

通常删除已在Methods出现的数据获取、暴露构建步骤、完整模型/协变量清单、插值和聚合过程、bootstrap实施与重拟合步骤、一般性假设及局限清单。保留本图必要的分面和颜色/形状说明、关键n与单位、误差线/阴影类型、P值的检验及校正含义、比较方向与基线。不同面板的时期窗口或分析单位不同时，必须保留区别。样本量或方法名只在读图确有需要时重复，不当成逐图必填清单。

优先顺序为：短总题 → 分面内容 → 必要的视觉编码和统计解释 → 影响本图理解的参照或限定。可以合并共享定义，避免逐面板重复。

视觉事实通常用现在时，分析操作按稿件时态；不把“电报体”设为硬要求。删除版本沿革、内部流程标识、绘图代码细节和与本图无关的辩解。保留会改变读者解释的条件与不利结果。

不将图注扩成 Results 的重复段落；结论性末句只在图和已核证据支持时使用。仅在确有对应交付时写 Source Data 可用；改编/转载的署名或许可按实际来源和权限说明，不自行声称获得许可。

## 执行与交付

1. 确定本次图号、当前图件和可用证据；制作简短的“面板—对象—样本—统计—参照”映射。
2. 起草或做最小必要修订。保持估计、区间、统计显著性及结论强度；将确需分析或绘图修复的问题单列。
3. 逐项对照实际图、Methods/Results和输出复核。按现有授权同步图注、合并稿、SI和受影响引用；若生成Word/PDF，使用相应文档流程重新渲染，页码从本次实际输出核实。
4. 交付可直接采用的图注或已更新文件，以及仅包含实质变更和未核项的简短记录。审核模式只给问题和建议，不自行改稿。

技能安装或规则检查不代表任何图注已审计通过；只有本次实际查看和核对的输入才在覆盖范围内。
