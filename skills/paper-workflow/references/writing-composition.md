# 语言层组合契约

`scientific-prose`、`anti-defensive-writing`、`lieflat-less-ai-tone` 都是语言层模块：只改表达，不改科学内容。三者同时启用时必须按固定顺序执行，并逐项记录改写归属。

## 顺序

1. 有新增或改动的文献时，先由 `citation-verifier` 核实身份与支撑关系；引用变更单独登记，不混进语言修订。
2. `anti-defensive-writing`：处理重复辩解、习惯性谦辞和段落重点偏移。先分类为冗余澄清、必要范围、方法局限或证据限定，再决定保留、压缩或等义改写。
3. `scientific-prose`：校准学科与章节语气，统一术语与格式，回查数字、比较对象、否定与限定词。
4. `lieflat-less-ai-tone`：按编号白名单处理命中的 AI 痕迹；英文正文按其 English academic mode 的最小改写映射执行，中文提要继续按原白名单。

## 共同边界

- 正文写作仍要求 G3 已批准；安装或升级工具不代表任何 Gate 批准。
- 不得为了语气更强或“更像人写”而删除：模型差异、跨零区间、共同系数缩放关系、反事实构造假设、情景外推条件、区间范围或生态学解释边界。
- 摘要和结论中，离开限定会造成误解的限定应保留在原处，不因“减少防御”而删。
- 不把所有否定句、转折、被动或长句都当成缺陷；不添加 robust、因果机制或效益表述。
- 引用补充与语言修订分开核对。
- 记录每项修改的模块、规则编号、前后文本和保留条件所在位置；无规则命中时可记录“不修改”。
- 保留旧稿，只更新正式分节稿、合并稿、相关登记册与变更日志。
