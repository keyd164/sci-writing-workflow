# 论证与段落计划
参考来源见 ../../paper-workflow/references/source-integration.md（Wenyu 主骨架）。
在起草前形成 manuscript/argument-map.md 与 manuscript/extended-outline.md 候选，不把它们当正文。
论证图贯通 gap → question → method → result → claim → contribution，并列 nonclaims（本研究不回答或不能推出的内容）。
每个计划段落登记：

| 段落 ID / 章节 | 读者此处需要解决的问题 | 段落功能 | C-id / 计划结论 | M/R/F/T 或文献依据 | 推断上限与缺口 | 与下段连接 |
|---|---|---|---|---|---|---|

方法段可承载定义或操作而非结果结论，不为凑表生成 C-id。planned 证据只能进入候选提纲，不能写成已有发现。
已有稿先做 reverse outline：每段实际功能、证据、重复或缺口，再调整提纲；不为服从旧提纲删掉不利发现。
自上检查每个研究问题有分析与证据，自下检查每个结果被合理解释且无贡献升级。已锁定项的改变先列建议，不直接改锁。
