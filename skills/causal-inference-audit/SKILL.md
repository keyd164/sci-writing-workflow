# causal-inference-audit
本技能只读审计，可在 G1/G2 批准前准备核验材料；不得据此放行下游写作。
读取 paper.yml、methods.yml、claims.yml、decisions.yml 和待审文本。
区分描述、条件关联、反事实比较、情景外推与因果效应；逐条核对 C-id 对应设计能支持的范围。
检查分析单位、暴露时间、混杂控制、固定效应/趋势、选择缺失、反向关系及外推假设是否说明；未提供模型或代码时标记未评估。
审查国家层面结果是否被写成个体风险，条件率差是否被写成已识别可避免病例数。
锁定决策仍可被审计质疑，但不得修改或绕过。输出位置/C-id/证据/风险/可采用措辞或待补分析；措辞建议不等于分析已成立。
报告遵循 paper-workflow 的输入身份与覆盖缺口约定；严重程度区分 blocking（影响当前所用证据）、major、minor，建议须有可定位依据。
