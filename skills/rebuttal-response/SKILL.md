# Rebuttal Response
读 paper-workflow、完整审稿意见、当前回复、最新正文/补充和有关登记册。
选择性参考 Nature-Paper-Skills 的逐项对应方法；来源见 ../paper-workflow/references/source-integration.md。
为每个可独立回答的子问题建立编号，输出 manuscript/reviewer-response-matrix.md：
意见/子问题、作者 accept/reject/defer 决定、所需动作、已完成证据、当前结果、正文实际位置、回复草案、未完成事项。
无作者决定时可诊断、准备方案与候选回复；不得默认 accept 或代过 G4。
作者接受的稿件修改交 evidence-drafting 执行；需要新分析时列任务与证据缺口，不写成“已完成”。
回复直接回答所问对象，说明证据及其范围；不接受时给可核验的理由。未改稿不能虚报页行号或引用不存在的新句。
交付 manuscript/rebuttal.md 候选；用实际提交版本复核页行号、图表、结果及补充材料。未完成项阻止宣称可提交。
回复完成后路由 alignment、受影响证据/引用核验及 submission-audit；正式发信/提交仍需用户授权。不新增工作流 Gate。
